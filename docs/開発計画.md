## 5. 残っている手順（人間が行う）

1. `.env.local` に `GOOGLE_API_KEY` を入れる（引用符で囲まない）
2. `npm run try -- "貧血気味で立っているとふらつく" 超満員 3` で生成が返ることを見る
3. `npm run pregenerate` で審査用データを作る
4. `vercel login` → `vercel --prod`。ダッシュボードで `GOOGLE_API_KEY` と `SOTTO_BLOB_KEY` を登録して再デプロイ
5. デプロイ先の URL で `mobile` を再ビルド：`flutter build apk --release --dart-define=SOTTO_API_BASE=https://<デプロイ先>`
6. APK を友人に渡し、[`手動確認.md`](手動確認.md) に沿って見てもらう。結果を `docs/spike-results.md` に
